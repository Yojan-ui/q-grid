### Why each item matters (for us, not for the email)

| Item | What it changes |
|---|---|
| Contract demand, maximum demand | the monthly demand charge (85 % floor, 2× above contract), which decides whether batteries pay for themselves |
| Tariff category, separate hostel meter | HT-2(c)(ii) Rs 8.50 vs HT-2(c)(i) Rs 7.50 per kWh; hostels may be HT-2(c)(i) |
| Which buildings the diesel sets back | which critical loads stay up in an outage: the headline reliability figure |
| Running hours, diesel logs, outage record | real outage frequency and diesel use instead of synthetic outages |
| Permission | lets us say "RVCE" in the pitch and report |
